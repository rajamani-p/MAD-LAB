# MAD-LAB

### Mobile Application Development Laboratory

This repository contains 12 Android application experiments completed as part of the Mobile Application Development Laboratory.

---

## Syllabus Experiments

1. Create an Android application to design a Visiting Card using layout components.
2. Create an Android application to build a basic Calculator using Buttons, TextView, and EditText.
3. Create a Sign-Up activity with Username and Password validation.
4. Create an Android application to set wallpaper and change it randomly every 30 seconds.
5. Create an Android application to display X, Y sensor values using the Sensor Service.
6. Create an Android application to implement a Start–Stop counter using buttons.
7. Create an Android application with two buttons to parse XML and JSON files, and display the parsed data in their respective layouts side by side.
8. Create an Android application to design a Phone Dialer with CALL and SAVE functionalities.
9. Create a simple Android application to convert text to speech using the TextToSpeech API.
10. Create an Android application to display the current location on Google Maps using Google Maps Service.

---
